# 야피아게임

6인용 실시간 웹 마피아 게임 MVP. Flask + Flask-SocketIO 기반이며 Render 배포 설정을 포함합니다.

## 포함 기능
- 방 생성 / 방 코드로 참가, 최대 6명
- 방장만 게임 시작, 6명일 때만 시작 가능
- 서버에서 무작위 역할 배정: 마피아 1, 의사 1, 경찰 1, 시민 3
- 원탁 좌석 UI, 생존/탈락 표시
- 역할 정보는 해당 플레이어의 소켓에만 전송
- 밤 행동: 마피아 제거, 의사 보호, 경찰 조사
- 낮 전체 채팅, 밤 마피아 비밀 채팅
- 방장 투표 시작, 모든 생존자가 투표하면 자동 판정
- 투표 동률 처리 및 승리 조건 판정

## 로컬 실행 (Windows PowerShell)

```powershell
cd 경로\yapia_game
py -m pip install -r requirements.txt
py app.py
```

브라우저에서 `http://127.0.0.1:5000` 접속. 다른 기기에서 접속하려면 같은 네트워크의 PC IP 주소를 사용하고 방화벽에서 5000 포트를 허용해야 합니다. 인터넷에 공개하려면 아래 배포 방법을 사용하세요.

## Render 배포
1. 이 프로젝트 폴더를 GitHub 저장소에 올립니다.
2. Render에 로그인해 **New + → Blueprint**를 선택하고 저장소를 연결합니다.
3. `render.yaml`을 인식하면 `yapia-game` 웹 서비스를 생성합니다.
4. 배포 완료 후 Render가 제공하는 `https://...onrender.com` 주소를 친구에게 공유합니다.

`Procfile`도 포함되어 있지만, `render.yaml`의 Start Command를 사용하면 됩니다.

## 게임 규칙
- 총 6명: 마피아(야동욱) 1, 의사(안서현) 1, 경찰 1, 시민 3.
- 역할의 이름은 본인 화면에만 공개됩니다. 공개 좌석에는 닉네임만 표시됩니다.
- 밤에는 마피아/의사/경찰이 각각 한 번씩 행동합니다. 세 행동이 접수되면 밤 결과가 처리됩니다.
- 경찰 조사 결과는 경찰 본인에게만 전달됩니다.
- 아침 후 방장이 토론을 마치고 투표를 시작합니다. 생존자 전원이 투표하면 자동으로 탈락자가 결정됩니다.
- 마피아가 모두 탈락하면 시민 팀 승리. 마피아 수가 다른 생존자 수 이상이면 마피아 팀 승리.

## MVP 주의사항
- 현재 방 상태는 메모리에 저장됩니다. 서버 재시작/슬립/재배포 시 진행 중인 방이 초기화됩니다.
- Render 인스턴스는 하나만 사용해야 합니다. 멀티 인스턴스/영구 저장을 위해서는 Redis 등의 공유 상태 저장소가 필요합니다.
- 이 버전은 친구끼리 테스트하는 MVP입니다. 공개 서비스로 운영하기 전에는 연결 재개, 속도 제한, 신고/차단, 더 엄격한 세션 검증과 보안 검토를 추가하세요.
- 브라우저를 새로고침하면 같은 토큰으로 재접속할 수 있지만, 방 코드와 닉네임을 다시 입력해 방에 재참가해야 할 수 있습니다.
